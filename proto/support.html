Support ideas – try them

Three things we agreed on, working for real on this page. Nothing here is live anywhere else.

1 · Thank-you note after the 3rd visit

A visit = one sitting (30 min without activity starts a new one). Counted only in the visitor's own browser. Shows once – closed or clicked, it never comes back.

Visits so far: 0

2 · Your name and supporter badge on the build picture

Both optional. The picture is the same one the calculator saves today.

3 · How a supporter gets the badge

  1. Someone donates on Ko-fi.
  2. Ko-fi sends the donation email to BigD.
  3. Main replies from the BigD Gmail within 48 hours with a code of the right rank, like FORGE-7K2Q.
  4. They type it once under “Have a supporter code?” – the ★ Supporter badge of their rank is on every picture they save on that device.

Ranks like talent ranks: Bronze 1/3 for the first donation, Silver 2/3 for the second, Gold 3/3 after that. Try the test codes above: FORGE-WV3R (bronze), FORGE-5ZL7 (silver), FORGE-VFS9 (gold) – remove the badge to try the next one. The site keeps no list of names – it only checks the code against a scrambled copy, so nothing about the donor is stored.

4 · Sharing

On phones, “Save picture” already opens the phone's share menu (Instagram, WhatsApp, Discord, Reddit…) – that's live today. On PC it downloads the picture.
